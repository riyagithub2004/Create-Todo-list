✅ To-Do List App:

A simple To-Do List application built using HTML, CSS, and JavaScript.
This was one of my beginner projects to practice web development and understand how to build interactive applications.

🚀 Features
➕ Add new tasks
✅ Mark tasks as complete
❌ Delete tasks
🎨 Clean and minimal UI

🛠️ Tech Stack
HTML → Structure of the app
CSS → Styling & layout
JavaScript → Logic for adding, deleting, and completing tasks
